# NOAI Prep: research and design notes

These notes were produced while building the website in `web/`. They are kept here so the facts, sources and design decisions can be checked and updated.

| File | What it contains |
|---|---|
| [research/official-facts.md](research/official-facts.md) | Verified facts about NOAI 2025, 2026 and 2027 (formats, dates, eligibility, selection funnel, IOAI results), each with a source and confidence level, plus contradictions and how they were resolved. Checked 14 Oct 2026. |
| [research/ioai-syllabus.md](research/ioai-syllabus.md) | The IOAI 2026 syllabus (the one NOAI tells students to follow), the competition format, and how past IOAI tasks map to it. |
| [research/noai-2026-final-programming.md](research/noai-2026-final-programming.md) | Analysis and beginner walkthroughs of the three NOAI 2026 Final programming tasks. |
| [research/noai-2025-programming.md](research/noai-2025-programming.md) | Analysis and walkthroughs of the NOAI 2025 programming tasks. |
| [research/ioai-selection-tests.md](research/ioai-selection-tests.md) | What Singapore's IOAI selection and camp tasks ask, and the skills ladder from NOAI to IOAI. |
| [research/resources-and-community.md](research/resources-and-community.md) | Free learning resources, exam strategy evidence, and visual-explainer inspiration. |
| [curriculum.md](curriculum.md) | The course design: parts, modules and lessons, with the judging scorecard and coverage maps. Each module's full design (concepts, analogies, visual-explainer specs) is in `web/src/curriculum/modules/<module>/.spec.json`. |

Some paths in these notes refer to working files that were used during research and are not part of the repository.
