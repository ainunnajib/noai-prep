AI models see everything (photos, sentences, exam scores) as lists of numbers. A **vector** is the name for such a list.

<Analogy>
Giving directions in an HDB estate: "walk 3 blocks east, then 4 blocks north". Those two numbers, `[3, 4]`, are a vector. You can write them down as a list, or draw them as one arrow from where you start to where you end up.
</Analogy>

## Two ways to see one vector

As a list: $v = [3, 4]$. As an arrow: start at the origin, go 3 across and 4 up. Both mean exactly the same thing.

<VectorPlayground />

<KeyIdea>
A vector is a list of numbers, and you can draw it as an arrow. Its **length** (the L2 norm) is $\lVert v \rVert = \sqrt{v_1^2 + v_2^2 + \dots}$.
</KeyIdea>

## Working out the length by hand

<Steps title="Length of v = [3, 4]">
  <Step title="Square each part">
    $3^2 = 9$ and $4^2 = 16$.
  </Step>
  <Step title="Add them up">
    $9 + 16 = 25$.
  </Step>
  <Step title="Take the square root">
    $\sqrt{25} = 5$. So $\lVert v \rVert = 5$.
  </Step>
</Steps>

<Mistake>
Adding the parts without squaring ($3 + 4 = 7$) gives a different quantity, the L1 norm. Exam options often include it as a trap.
</Mistake>

## In Python

```python
import numpy as np

v = np.array([3, 4])
print(np.linalg.norm(v))   # 5.0
```

<Takeaways>
- A vector is a list of numbers, drawn as an arrow.
- Length (L2 norm) $= \sqrt{\text{sum of squares}}$.
- `np.linalg.norm(v)` computes it in NumPy.
</Takeaways>
